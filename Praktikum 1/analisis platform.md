# Analisis Platform: Web, Desktop, dan Mobile

## 1. Komparasi Karakteristik Platform

### A. Web

* **Bahasa Utama:** HTML, CSS, JavaScript, PHP, Python.
* **Arsitektur:** Client-Server (Frontend & Backend terpisah).
* **Cara Distribusi:** Melalui server web, diakses via URL/Domain browser.
* **Keunggulan:**
* Tidak perlu instalasi
* Bersifat *cross-platform* secara universal
* Mudah diperbarui


* **Keterbatasan:**
* Bergantung penuh pada koneksi internet
* Akses terbatas terhadap hardware perangkat keras
* Performa bergantung pada browser pengguna


* **Contoh Aplikasi:**
* Google Workspace (Docs, Sheets)
* Trello
* GitHub Web



### B. Desktop

* **Bahasa Utama:** C#, C++, Java, Python, Swift.
* **Arsitektur:** Standalone / Client-Server lokal.
* **Cara Distribusi:** Installer mandiri (`.exe`, `.msi`, `.dmg`, `.deb`) atau App Store khusus desktop.
* **Keunggulan:**
* Performa tinggi dan akses penuh ke hardware lokal
* Dapat berjalan secara *offline* dengan optimal
* Keamanan data lokal lebih terjaga


* **Keterbatasan:**
* Ukuran file instalasi cenderung besar
* Proses distribusi/update manual atau melalui toko aplikasi desktop
* Terikat pada sistem operasi tertentu


* **Contoh Aplikasi:**
* Microsoft Office (Word, Excel)
* Visual Studio Code
* VLC Media Player



### C. Mobile

* **Bahasa Utama:** Kotlin, Swift, Dart, JavaScript.
* **Arsitektur:** Mobile App Architecture (MVC, MVVM, Clean Architecture berbasis sistem operasi mobile).
* **Cara Distribusi:** Toko aplikasi resmi (Google Play Store, Apple App Store, APK manual).
* **Keunggulan:**
* Integrasi mendalam dengan sensor perangkat (GPS, kamera, biometrik)
* Mobilitas tinggi dan selalu ada di genggaman pengguna


* **Keterbatasan:**
* Keterbatasan kapasitas memori, baterai, dan ukuran layar
* Proses *review* dan publikasi aplikasi ke store yang ketat
* Fragmentasi perangkat yang tinggi


* **Contoh Aplikasi:**
* WhatsApp
* Instagram
* Google Maps
